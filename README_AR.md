# ITS Android starter

هذا المشروع يحتوي على واجهتين أوليتين لتطبيق ITS، مع GitHub Actions لبناء ملفي APK.

## البناء
- ارفع محتويات هذا المجلد إلى جذر مستودع `ym-live` على الفرع `main`.
- سيبدأ GitHub Actions بالبناء تلقائياً عند Push، أو شغّل `Build ITS APKs` يدوياً من تبويب Actions.
- نزّل artifact باسم `ITS-Android-APKs` من صفحة التشغيل.

## حدود هذه النسخة
هذه نسخة واجهات أولية فقط. إرسال الرسائل والوسائط، استقبالها، إشعارات FCM، الاقتران، تشغيل الصوت بالخلفية، وجدولة تحية الساعة 8 صباحاً غير مفعّلة بعد وتحتاج تنفيذ وربط API وFirebase واختبارها.
